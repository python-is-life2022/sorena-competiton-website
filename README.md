# Sorena — Top / Hero exact Figma build

این نسخه فقط بخش بالایی Frame با Node ID `1:2` را پیاده‌سازی می‌کند و هیچ‌کدام از بخش‌های پایین صفحه را وارد نمی‌کند.

Frame مبنا: **1440 × 860 px**

مختصات عناصر اصلی، اندازه‌ها، رنگ‌ها، سایه، فونت/وزن، تصاویر و استیکرها از Design Context همان Frame گرفته شده‌اند.

## اجرا

فایل `index.html` را با مرورگر باز کنید.

## نکته درباره assetها

برای حفظ تطابق دقیق، assetهای استخراج‌شده از Figma مستقیماً با URLهای Figma استفاده شده‌اند. این URLهای asset موقتی هستند و ممکن است بعد از مدتی منقضی شوند. در مرحله بعد می‌توانیم همین assetها را داخل پروژه local کنیم.

این نسخه عمداً فقط Hero/Top را دارد؛ About و هیچ سکشن دیگری کدنویسی نشده است.
